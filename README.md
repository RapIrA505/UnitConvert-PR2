# UnitConvert

Простое приложение для перевода температуры, длины и массы.
Практическая работа № 2 по тестированию программного обеспечения.

Разработчик: Молдаванский Р.Д.  
Тестировщик: Белов А.М.  
Группа: ИКБО-43-24. Команда: «Крутые перцы».

## Что умеет приложение

- Переводить градусы Цельсия в градусы Фаренгейта и обратно.
- Переводить километры в мили и обратно.
- Переводить килограммы в фунты и обратно.
- Сообщать об ошибке, если введено не число или недопустимое значение.

## Запуск

Нужен Python 3.12 или новее с Tkinter. Дополнительные библиотеки для запуска не нужны.
Откройте терминал в папке приложения и выполните:

```powershell
python app.py
```

Выберите перевод, введите число и нажмите «Перевести» или Enter.
Дробную часть можно отделять точкой или запятой. Длина и масса не могут быть
отрицательными, а температура — ниже абсолютного нуля.

## Проверка тестами

`app.py` отвечает за окно, `core.py` — за расчёты.
В `tests_initial` находятся первые тесты, в `tests_improved` — проверки,
добавленные после мутационного тестирования.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -m pytest tests_initial tests_improved -q
```

Ожидаемый результат: **39 passed**.
