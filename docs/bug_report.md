# Баг-репорт UC-001

**Заголовок:** неверный коэффициент при переводе градусов Фаренгейта в Цельсия.

**Предусловие:** импортировать `core.py` версии 1.0. **Шаг:** вызвать `fahrenheit_to_celsius(212)` либо выбрать «Температура: °F → °C» в интерфейсе, использующем модуль 1.0, и ввести `212`.

**Ожидается:** `100.0` °C по F2 технического задания. **Фактически:** `112.5` °C. Дополнительное воспроизведение: `−40` °F преобразуется в `−45.0` °C вместо `−40.0` °C. При `32` °F дефект не проявляется, поскольку множитель применяется к нулю.

**Причина:** `(value - 32) * (5 / 8)` вместо `(value - 32) * (5 / 9)`. Изменена только ошибочная формула и обозначение версии. Исходный дефект сохранён для демонстрации.

**Проверка:** исходный набор из 24 тестов даёт 2 отказа и 22 успешных проверки на 1.0; тот же набор даёт 24 успешных проверки на 1.1. Подтверждение — `verification/v1_0_initial.log`, `verification/v1_1_initial.log` и JUnit XML. Это результаты автоматического запуска, а не утверждение о состоявшемся ручном обмене между студентами.
